# S-MU2000 液晶の字（手描き）
#
# 手元にある字形 ROM（MAME の mulcd.zip の hd44780u_b04.bin）は MU2000 自身の
# ものではないらしく、記号のところが実機と違う。実機の画面を見ながら 1 マスずつ
# 描き起こしたものを、ここに書いて上から被せる。
#
# **ROM から起こした字は入れないこと。** ここに入れてよいのは、実機の画面を
# 見て人が描いたものだけ。
#
# 書き方: 2 桁の 16 進で字のコード（そのあとに覚え書きを書いてよい）、
# つづけて `.` と `#` だけの行を 8 行。1 行 5 桁。`#` が点。
#
#   使い道を調べる: python tools/lcdfont.py where 10
#   いま何が出ているか: python tools/lcdfont.py show
#   ROM の字を下書きに出す（**この中に貼らないこと**）:
#       python tools/lcdfont.py dump 10-1f > .local/rom-font.txt
