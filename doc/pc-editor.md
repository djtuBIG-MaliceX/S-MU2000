# PC で触る窓（一覧・エディタ・インサーションの設定・パートの音色・マスター）

gui.exe の中で開く、**マウスとキーボードで触るための窓**。パネルの絵とは別の窓に出る。
パラメータの層（[params.md](params.md) の作る順 5 番）の上に作った。用途で分けている。

| 窓 | 用途 | 開き方 |
|---|---|---|
| **一覧** | 曲を流しながら、全パートを見渡してバランスを整える（Domino のトラック一覧の形） | F3・右クリック・`--list-window` |
| **エディタ** | 1 つのパートを作り込む。今は表とつまみの仮の形で、Sonar のような形に作り直す予定 | F2・右クリック・`--editor` |
| **インサーションの設定** | インサーション 1-4 の種類ごとのパラメータを、実物のエフェクターのようなつまみで触る | 一覧でインサーションの欄をダブルクリック・`--fx-window` |
| **パートの音色** | 1 つのパートの VIB・FILTER・EG・EQ の絵を大きく出して触る。値の棒でも合わせられる。左に音色を選ぶ面が出しっぱなしで、続けて音色を替えられる（左に分類、右の上に基本の音色、右の下にいまの音色のバンク違い）。今と違う分類を押すとその分類の先頭の音色（キットなら先頭のキット）に替わる。音色を替えるたびに、そのパートの受信チャンネルで 1 秒だけ試聴の音を鳴らす（ドラムはスネア、ほかは C4）。音色の切り替えは、受信チャンネルがそのパートだけのものならバンクセレクトとプログラムチェンジで送る（LCD に Ex の印を出さないため。チャンネルが OFF やほかのパートと共有のときはパラメータチェンジ） | 一覧で VIB・FILTER・EG・EQ の絵をダブルクリック・`--shapes-window` |
| **マスター** | マスターボリューム・マスターチューン・移調、リバーブ・コーラス・バリエーションの種類と戻り、マスター EQ をまとめて触る | 一覧のマスターの行の MASTER の名前か MASTER EQ の絵をダブルクリック・`--master-window` |

どれも閉じても隠すだけなので、開き直すと同じところから出る。同時に開ける。

## 一覧

1 行 = 1 パート（32 行）。列の前半は Domino の並び、後半は**音の流れの順**
（音色を作るもの → パートの EQ → インサーション → 送り）。

| 列 | 中身 |
|---|---|
| パート | パート名・音色（番号と GM の名前）・受信チャンネル・バンク。**右クリックでプログラムとバンクを選ぶ** |
| VEL | ノートオンの強さで跳ねて、落ちていくメーター |
| VOL・PAN・VAR・CHO・REV | XG の値。**触れる**（左右か上下にドラッグ、ホイール、ダブルクリックで打つ） |
| EXP・P.BEND・MOD・HOLD | 演奏の値（CC11・ピッチベンド・CC1・CC64）。表示だけ（赤い棒） |
| VIB | ビブラートの揺れの形。平らな所が掛かり始めるまで |
| FILTER | 2 次のローパスの特性の山 |
| EG | 音量の形（アタック → ディケイ → 伸ばし → リリース）を折れ線で描く |
| EQ | パートの EQ（08 pp 72-77）。低音と高音のシェルフの合わさった特性 |
| INS | このパートだけに掛かっているエフェクト。印 `1`-`4` がインサーション、`V` が接続 INSERTION のバリエーション。掛かっている印を横に並べるだけで、種類の名前はカーソルを載せると出る（名前まで見るならパートの音色の窓の上のペイン）。**右クリックで掛ける・外す・種類を選ぶ。印をドラッグして別のパートの INS 欄に落とすと移る**（バリエーションは INSERTION になる）。**印 `1`-`4` をダブルクリックすると設定の窓** |
| 鍵盤 | 128 鍵。押さえている鍵が光る。**マウスで弾ける**（左右どちらのボタンでも。押すとノートオン、離すとノートオフ、押したまま横に動かすと鍵が替わる。下ほど強い）。送り先はそのパートの受信チャンネルで、口 A のパートは THRU A にも流れる、口 B のパートは流れない |

**表示の大きさ**は上の欄の `-` `+` で変える（50〜150%、既定 63% = 文字 10px。`%LOCALAPPDATA%\S-MU2000\editor.ini` に覚える）。
上の欄の右端に**同時発音数と CPU の負荷**（`発音 112/128 (M:64, S:48)`、`CPU 26%`）。数字の後ろに棒を敷く（発音数はマスタを青、スレーブを橙で積み、全体が 128。CPU は 0〜100% で、60% から黄、85% から赤）。数字は桁数ぶんの枠に右寄せで置くので、演奏中に桁が変わっても文字の位置は動かない。発音数は SWP30 2 個（マスタとスレーブ、64 ずつ）の声のうち、
エンベロープが止まっていないものの合計（離して消え切るまでを含む。1 音で 2 つ以上の声を使う音色もある）。
firmware はマスタの 64 から使い、埋まるとスレーブに回す（1 声の音色で 112 音を重ねると、マスタ 64 + スレーブ 48 になった）。
CPU は音声の処理にかかる時間の、締め切りに対する割合で、gui.exe のときだけ出す（プラグインではホストが回すので出さない）。
同じ発音数はパネルの窓の下の帯（CPU の前）にも出る。
32 パートを見渡すための窓なので小さめにしてある。VIB・FILTER・EG・EQ の小さな絵は**見るだけ**で、
マウスでは値を変えない。**ダブルクリックするとパートの音色の窓に大きく出るので、変えるのはそこで**。

VIB・FILTER・EG の値は音色の元の値に対する増減（64 が音色のまま）。形は 2 の (値 - 64) / 24 乗
などで伸び縮みさせた見た目で、実際の秒数や周波数ではない。EQ の周波数の軸は実際の周波数
（20Hz-20kHz の対数）で、形は目安。

パートの欄の右端の **M でミュート、S でソロ**（S を入れたパートだけが鳴る。いくつでも入れられる）。
ミュートはパートの受信チャンネルを OFF にして行い（先にそのチャンネルへオールサウンドオフ）、
外すと元のチャンネルに戻す。曲の XG リセットなどで受信チャンネルが書き換わったら、もう一度 OFF にする。
一覧の窓を閉じたときと、gui.exe を終えるときに全部外す（受信チャンネルを戻してから音源の状態を保存する）。

PAN・P.BEND は真ん中から左右に棒が伸びる。

**上にマスターの表**（パートの表とは見出しが別。スクロールしても残る）。こちらも音の流れの順。

| 列 | 中身 |
|---|---|
| マスター | 移調（Transpose）とマスターチューン。**ダブルクリックでマスターの窓** |
| M.VOL | マスターボリューム |
| INS 1-4 | インサーション。種類と掛けるパート。**右クリックで種類と掛けるパート、つかんでパートの表の INS 欄に落としても掛けられる。ダブルクリックで設定の窓** |
| VARIATION | バリエーション。上の行が種類と接続（INSERTION なら `→ A4`）、下が戻り量。**右クリックで種類と接続（SYSTEM / INSERTION と掛けるパート）** |
| CHORUS・REVERB | システムのコーラス・リバーブ（全パートで 1 台ずつ共有）。上の行が**種類（右クリックで HALL 1 などを選ぶ）**、下が戻り量 |
| MASTER EQ | マスター EQ（02 40 00-14、5 帯）の特性。**見るだけで、ダブルクリックでマスターの窓**（触るのはそこで） |
| 鍵盤 | 全パートで鳴っている鍵を重ねる。色はパートごと（隣どうしが似ないよう色相を 7 つ飛ばしで振る）、同じ鍵を複数のパートが鳴らしていれば色を混ぜる |

パートの表の REV・CHO・VAR は、そのパートからの**送り量**。種類は持たない。
**バリエーションの接続が INSERTION のときは、パートの VAR とマスターの戻り量を薄く出す**
（INSERTION のときは送り量も戻り量も使われず、1 つのパートの通り道に直に入るため）。

## パートの音色

一覧の VIB・FILTER・EG・EQ の絵をダブルクリックすると開く。上でパートを選び（A1〜D16。`◀` `▶` で前後）、
**一覧で行をクリックしても、この窓がそのパートに替わる**（行のどの欄でもよい）。
左に音色を選ぶ面、右の 4 つの区画に一覧と同じ絵を大きく描き、点をつまんで変える（一覧の小さな絵は見るだけ）。

**上のペイン**には、一覧の行と同じ部品を並べてある。

| 行 | 中身 |
|---|---|
| エフェクト | 左にこのパートに掛かっているインサーション 1-4 の印と**種類の名前**。触り方は一覧の INS 欄と同じ（右クリックで掛ける・外す・種類、印のダブルクリックで設定の窓、ドラッグで一覧の別のパートへ）。同じ行の **VAR の棒の真上からバリエーションの種類**（このパートに INSERTION で掛かっていれば V の印で、触り方は INS 欄と同じ。ほかのパートに掛かっていれば `→ A4` のように。SYSTEM なら名前だけで、下の VAR の棒が送り量） |
| 棒 | VOL・EXP・PAN・P.BEND・MOD・HOLD と VAR・CHO・REV を窓の幅いっぱいに並べる。一覧と同じく、XG の値（VOL・PAN・VAR・CHO・REV）は**ドラッグ・ホイール・ダブルクリックで打つ**で変えられる。EXP・P.BEND・MOD・HOLD は演奏の値で見るだけ。9 本とも同じ幅 |
| 鍵盤 | このパートの鍵盤（窓の幅いっぱい）。押さえている鍵が光り、**左クリックで鳴る**（受信チャンネルへ送る）。**右クリックした鍵に緑の目印**が付き、音色を替えたときの試聴はその鍵で鳴る（別の鍵を右クリックすると目印が移る。`editor.ini` の `audition_note` に覚える）。左の端の縦の溝は**モジュレーションホイール**（CC1）で、カーソルを載せてホイール（Ctrl で大きく）か上下にドラッグ |

**PC のキーボードで弾ける**（この窓が前にあるとき）。`A` `W` `S` `E` `D` `F` `T` `G` `Y` `H` `U` `J` `K` `O` `L` `P` `;` が C から半音ずつ（白鍵が A S D F G H J K L ;、黒鍵が W E T Y U O P）。
`Z` / `X` でオクターブを下げる・上げる（最初は A が C3 = ノート 60）。弾ける範囲は鍵盤の下に青い線で出る。
強さは 100。数を打つ箱に文字を打っている間と、Ctrl・Alt を押している間は弾かない。窓を閉じたり外に出たりすると、鳴らしている音は止める。

| 絵 | つまみ方 |
|---|---|
| VIB | 波の山の点を横で速さ（左へ速く）、縦で深さ。平らな所の終わりの点を横で Delay |
| FILTER | 頂の点を横でカットオフ、縦でレゾナンス |
| EG | 3 つの点を横につまむと、アタック・ディケイ・リリースが変わる（右へ長く、左へ短く） |
| EQ | 点 1（低音）・点 2（高音）を横で周波数、縦でゲイン（±12dB） |

点は押した瞬間に一番近いものをつかみ、指とのずれを保つので、点の上でなくてもつまめる。
絵の下に値の棒があり、ドラッグか、Ctrl+クリックで数を打つ。EQ の周波数は Hz で出す。

## マスター

一覧のマスターの行の MASTER の名前か MASTER EQ の絵をダブルクリックすると開く。表示の大きさは右上の `-` `+`
（既定 80%。`editor.ini` の `master_zoom` に覚える）。

| 区画 | 中身 |
|---|---|
| システム（上の左） | マスターボリューム、マスターチューン（0.1 セントの目盛り）、移調（半音） |
| システムエフェクト（上の右） | リバーブ・コーラス・バリエーションの種類（品書きの形で選ぶ）、戻り量、パン、コーラス・バリエーションからリバーブへ・バリエーションからコーラスへの送り、バリエーションの接続（INSERTION / SYSTEM）と掛けるパート（INSERTION のときだけ） |
| マスター EQ（下） | 種類（FLAT / JAZZ / POPS / ROCK / CONCERT。選ぶと firmware が 5 つの帯をその値に書き換える）、帯 1・5 をピークにするか（外すとシェルフ）、5 つの帯の特性の絵（点を横で周波数、縦でゲイン、点の近くでホイールを回すと Q）、帯ごとのゲイン・周波数・Q の棒 |

エフェクトの中身のパラメータ（リバーブの時間など）はまだ出していない。

## 音色の名前と楽器の絵

一覧のパートの欄には、**MU2000 の LCD と同じ音色の名前**（`RockOrg#`、`Arco Str` など）と、
**楽器の絵**（16×16 ドットを実機の LCD に寄せて横 2 : 縦 1、LCD の色）を出す。どちらも**利用者のプログラム ROM から実行時に読む**
（`src/xg/voices.h`）。名前も絵もリポジトリには入れない。

ROM の版が違って番地が合わないときは使わず、GM の名前（`Acoustic Grand Piano` など）で出す。
番地は MU2000 EX（firmware v2.01）で調べた。

**右クリックの音色の品書き**も ROM から作る。**分類（Piano など 16）→ 基本の音色（プログラム番号。
MSB 0 / LSB 0 の名前）→ その音色のバンク違い（MSB / LSB と名前）** の 3 段。バンク違いの無い番号は
2 段目でそのまま選べる。最後にドラムキット（MSB 127）と効果音キット（MSB 126）。

firmware の引き方（`0x134AA8`）を `voice_rom::lookup` に移した。モード（RAM の `0x4226BC`）と
組の選び方（`0x4226DE`）を写しで受け取り、MSB → 組の表と、組 × プログラムの表を引く。
ランダムな 600 組でパートの +0xF8 と突き合わせて 596 組が一致した。残る 4 組は、続けて
切り替えたときだけ firmware が違う音色を選び、1 組ずつ試すと一致する（直前の状態で変わる規則が
まだある）。**画面の名前と絵は firmware の選んだ +0xF8 から出す**ので、ずれるのは品書きの
候補の名前だけ。

調べ方と分かったこと:

* **音色の記録**: `0x200EE0` から 1635 個。「要素の印 1 バイト（ビットごとに要素）・1 バイト・
  名前 10 文字」で始まり、長さは 14 + 84 × 要素の数
* **パートが選んでいる音色**: パートの塊（`xg/ram.h`）の **+0xF8 に、その記録を指す値**がある。
  firmware がバンク・プログラムから引いた結果（引く関数は `0x134AA8`。モードとバンク MSB から
  「音色の組」を決め、`0x267F50` の表を組 × プログラムで引く）。これを RAM の写しで読むので、
  バンクの規則を真似しなくてよい
* **ドラムキット**: +0xF8 は 0。バンク 127 は `0x299FCC`（プログラム → 番号）と `0x299DC0`
  （名前 8 文字 + 4 バイトの並び）、バンク 126 は `0x29BE58` と `0x29BDEC`。LCD の名前と一致した
* **楽器の絵**: 16 ワード（1 行 16 ビット、上の桁が左）。`0x1BBF70` から 32 バイトずつ。
  通常の音色は **プログラム番号で決まり**（`0x1CD044` の 128 バイトの表）、バンク LSB が違っても
  同じ絵。効果音（MSB 64）は 57 番、Silence は 56 番
* **ドラムの絵**: どのキットも同じ絵で、`0x1CD0E4`（上の 128 バイトの表のすぐ後ろ）。
  そこには起動のときの動く絵のコマが 32 バイトずつ並んでいて、その 2 コマ目。LCD は 1 マス 5 ドット ×
  3 マスで 15 列しか出さないので、右端の 1 列（最下位ビット）は消して出す。前に見つからなかったのは、
  CGRAM から拾った絵にその 1 列が無く、ROM とそのままでは一致しなかったため

LCD の文字の型（CGRAM）に描かれた絵を拾い、firmware が ROM を読む命令の場所を捕まえ
（`0x0C58D8` が絵を描く、`0x134A66` が記録を読む）、機械語を読んで確かめた。

## 説明（ヘルプ）と言語

窓の上の **「説明を出す」** を入れておくと、見出しやパラメータの名前にカーソルを当てたとき、
それが何に効くのかを出す（一覧とエディタの両方）。言語は隣の欄で日本語と English を選ぶ。
どちらも `%LOCALAPPDATA%\S-MU2000\editor.ini` に覚えておく。

文は `src/ui/xg_ui.cpp` の `HELP` に「キー → 言語ごとの文」で並べてある。言語を足すときは
`LANGS` に 1 つ足し、各行に文を 1 つ足す（無い言語は日本語で出る）。

# インサーションの設定の窓

一覧のマスターの INS 1-4、またはパートの INS 欄の印 `1`-`4` をダブルクリックすると開く。
上の帯で INS 1-4 の切り替え、種類、掛けるパート。その下に種類の系統ごとの色の筐体
（残響は青、ディレイは青緑、揺れは紫、歪みは赤、EQ は灰、そのほか緑）と、パラメータの数だけのつまみ。

つまみは上下ドラッグ（全域で 200px ほど、Shift で 4 倍細かく）、ホイール（Ctrl で 10 倍）、
ダブルクリックで数を打つ。値の表示は LCD と同じ文字（`2.1`、`D24>W`、`5.6k`、`333.3` など）。

**説明**: 名前の下に種類の説明、下の欄にカーソルを載せた（最後に触った）つまみの名前・値・説明を出す。
種類の品書き（一覧の右クリック、この窓の種類の欄）でも、項目にカーソルを載せると種類の説明が出る。
文は `src/ui/fx_help.cpp`。何をする種類・パラメータなのかは MU1000/MU2000 のオーナーズマニュアルと
MU2000 Extended Edition 追加機能説明書のエフェクトタイプリストとパラメーター解説で確かめ、
文はこちらで書いた（写していない）。テンポに合わせる種類（TEMPO DELAY、SLICE など）は、
シーケンサーから MIDI クロックを受けないとテンポに合わない。説明を出す・言語の設定は一覧と共通。

**種類の一覧**は、firmware がパネルで種類を選ばせる表（番号と LCD の名前 10 文字）を実行時に ROM から読む
（`xg::set_fx_type_rom`。リバーブ 19・コーラス 21・バリエーションとインサーション 118）。
品書きは分類（リバーブ・ディレイ・歪み・EQ など。分け方は画面の都合で決めた）→ 系統（MSB）→ LSB 違い。

**種類の印**: 分類ごとに小さな絵を決めてある（`src/ui/fx_icons.cpp`）。品書きの分類の頭、この窓の名前の左、
パートの音色の窓の上のペインのエフェクトの名前の前、種類を選ぶ箱（この窓とマスターの窓）に出る。線で描くので大きさを変えても粗くならない。

| 分類 | 絵 |
|---|---|
| リバーブ | 点から広がる 3 本の弧 |
| 初期反射・ゲート | 長さのばらばらな縦の線 |
| ディレイ・エコー | だんだん小さくなる丸 |
| カラオケ | 台に立てたマイク |
| コーラス・セレステ | ずれた 2 本の波 |
| フランジャー・フェイザー | だんだん細かくなる波 |
| 回転・トレモロ・パン | 回る矢印 |
| 歪み・アンプ | 頭のつぶれた波 |
| EQ・ワウ・フィルタ | 山のある特性の線 |
| コンプ・ゲート | 上下から押す矢印 |
| 組み合わせ | 線でつないだ 3 つの箱 |
| ローファイ・テクノ | 階段の波 |
| ピッチ・その他 | 音符と上向きの矢印 |
| NO EFFECT / THRU | 斜線の入った丸 / まっすぐな矢印 |

**パラメータの表は firmware の LCD から作った**（`src/xg/fx_params.h`、手で直さない）:

1. `tools/fxsweep/fxsweep.cpp` が、インサーション 1 の種類を 1 つずつ変え、パネルのボタンで
   EFFECT → INS → INS1 の編集画面に入り、SEL> で 1 ページずつ進む
2. ページごとに、候補の番地に 0 と最大を書いて LCD の 2 行目が変わる番地を探す。候補の順は
   2 バイトの 30-43 → 1 バイトの 02-0B → 20-25
3. 見つかった番地に 0 と最大を書いて RAM を読み、受け付ける範囲を得る。範囲の値を 1 つずつ
   書いて LCD の表示を拾う（128 を超える範囲は間引く）
4. `tools/fxsweep/make_fx_params.py` が、名前・番地・範囲と、表示の並び（同じものはまとめる）を
   ヘッダにする。数のままのものと 10 分の 1（ディレイの時間）は式で出す

分かったこと:

* **パラメータ 1-10 は種類で番地が違う**。ディレイ（DELAY LCR / L,R / ECHO / CROSS DELAY）は
  2 バイトの値なので 30-43（MSB, LSB の組が 10 個）で書く。ほかの種類は 02-0B で、30-43 に書いても効かない
* RAM では、塊の +0x02-0x0B に 1 バイトの値、+0x18 から 16bit の数（上位バイトが先）で 10 個。
  パラメータ 11-16（20-25）は +0x12-0x17。層へは 16bit の数を 30-43 の形に崩して入れる（`panel::tick`）
* ディレイの時間は 0.1 ミリ秒単位で最大 1486.0
* 種類の表（`src/xg/fx_types.h`）の GATE REVERB と REVERSE GATE の番号が 1 つずれていた。
  LCD の種類の表示で、0x0A が GATE REV、0x0B が REVRS GATE。0x0C を書くと THRU になる
* ER 1 の Early Type、GATE REVERB の GateType、AMP SIM の AmpType は、名前に `Type=` を含むので、
  種類のページと取り違えないよう行の頭で見分ける

# エディタ

## 面

| 場所 | 中身 |
|---|---|
| 左の一覧 | 32 パート。受信チャンネル、音色（番号と GM の名前、ドラムは Drum Kit）、音量。行を選ぶとそのパートになる。**右クリックでプログラムとバンクを選ぶ**（GM の 16 分類ごとの小品書き）。幅はつまんで変えられる |
| ミキサー | 32 パート × Volume・Pan・Dry・Reverb・Chorus・Variation |
| パート | 選んだパートのマルチパート 41 バイト全部。音色／音量と送り／受信と発音／フィルタと EG／ビブラート／モジュレーション／ピッチベンド |

上の帯に `XG リセット`・`オールノートオフ`・**`▼ つまみを出す`**。普段は値を数の箱で並べ、
押すとつまみ（輪と指し、Pan や ±の値は真ん中から）になる。ミキサーもパートの面も同じ。

## 触り方

| | |
|---|---|
| 上下ドラッグ | 値を動かす（全域で 200px ほど。Shift で 4 倍細かく） |
| ホイール | 1 つずつ（Ctrl で 10）。**表をスクロールしている最中（直前 0.5 秒）は表に回す** |
| ダブルクリック | 数を打つ（打つのは生の値。Pan なら 0-127、Note Shift なら 40-88） |
| マウスを置いて待つ | 名前・いまの値・既定の値 |

数の箱でもつまみでも触り方は同じ。選ぶ種類の値（MONO/POLY、受信チャンネルなど）は品書き。

表示は名前（`L12`、`+3`、`POLY`、`B5` など）。受信チャンネルは `A1`-`A16`・`B1`-`B16`・`OFF`。

## 値の出どころ

**画面では覚えない。MU2000 に問い合わせもしない。** 音声の糸が 25ms ごとに firmware の
ワーク RAM から XG の値を写し（`ui::driver::publish_xg`、番地は `src/xg/ram.h`）、
画面の糸がそれをパラメータの層（`xg::model`）に入れる。曲・Domino・SysEx・フロントパネルの
どれで変えた値も、そのまま出る。

前は MU2000 に一括ダンプを頼んで読み返していたが、頼みごとは MIDI IN に入るので LCD の
受信マークが点きっぱなしになっていた。いまは触ったとき（パラメータチェンジを送るとき）しか
MIDI は流れない。

書いた直後の 0.5 秒は、RAM の古い値で上書きしない（層の決まり）。
バンクを書くと今のプログラムも続けて送るので、すぐ効く。

鳴っている鍵とベロシティは RAM からはきれいに取れないので、音源へ入れた MIDI を
`ui::driver::watch` で数えて写しに入れている（口 × チャンネルごと）。

## 中の作り

```
ui::imgui_view  窓の中身の口（xg_ui.h）。一覧（ui::overview）とエディタ（ui::pc_editor）
ui::pc_window   Win32 の窓と Direct3D 11。窓ごとに ImGui の文脈を持つ。
                gui のタイマー（30 コマ／秒）から frame() を呼ぶ
ui::xgui        共通の小物（GM の名前、プログラムの品書き）
```

写しを層に入れるのは `panel::tick`。エディタも同じ層を読む。どちらも画面の糸で動くので、層に錠は要らない。

字は Windows に入っている游ゴシック（無ければメイリオ、MS ゴシック）を読む。配らない。
DPI 対応はプロセス全体に効いてパネルの窓まで変わるので宣言していない
（高 DPI の画面では Windows が窓ごと拡大する）。

## これから作るもの（持ち主と決めたこと）

* **チャンネルの窓**（Sonar の形）。一覧とは別の窓。左に選んだパートの詳しいつまみ、右に全パートの帯
  （スクロールで見る）。帯をクリックすると左がそのパートに替わる。バリエーション・インサーションの
  枠は出したり隠したりできる。エフェクトの細かい設定はさらに別の窓
* **EG の平面**（SOL2 の形）。一覧の EG の列に小さく入れた（上）。チャンネルの窓で大きく出すかは、使ってみて決める。
  FILTER・VIB・EQ も同じ形で一覧に入れた

## まだ無いもの

* エディタの窓はまだ GM の名前
* リバーブ・コーラス・バリエーションの細かい設定の窓（インサーションと同じ形で作れる）、ドラムのセットアップ、システム
* 保存と読み込み（塊のダンプをそのまま `.syx` にする）
* VST3 の画面に載せる
