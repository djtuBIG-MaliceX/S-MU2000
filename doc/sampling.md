# サンプリングして、MIDI の音源として鳴らすまで

MU2000 は**外から入れた音を録って、その音を MIDI の音色として鳴らせる**。ここでは
A/D INPUT に音を入れるところから、シーケンサや DAW から鳴らすところまでを順に書く。

この文書の手順は、**エミュレータの firmware を実際に動かして確かめたもの**（画面の文字は
そのまま写した）。確かめていないところは、そう書いてある。

| | |
|---|---|
| サンプリング RAM | 標準で **4096KB**（`SAMPLING` → `RAM` で `USED` と `FREE` が見られる）。録れる長さは 48 秒ほど |
| 録り方 | 44100Hz・16bit。入口は A/D INPUT の 1（左）と 2（右） |
| 電源を切ると | **消える**。残すなら SmartMedia へ保存する（下の 6.） |
| DAW では | プロジェクトに残る（機械まるごとの状態に入る。下の 7.） |

## 1. 音の入口を用意する

| 使い方 | やること |
|---|---|
| `gui.exe` | パネルの **`A/D INPUT` のジャックを左クリック**（窓のどこかを右クリックでもよい）して、録音デバイスを選ぶ。左が AD1、右が AD2。44100Hz でなければ中で直す |
| VST3・CLAP・AU | 補助の音声入力バス **`A/D Input`**（ステレオ）に繋ぐ。DAW ではサイドチェーンの入力として見えることが多い。左が AD1、右が AD2 |

**入れた音をそのまま聞きたいときは、A/D パートの音量を上げる。** 初期値は 0 なので、
何も聞こえないのが正しい。XG のパラメータチェンジで上げる（AD1 が `10 00 0B`、AD2 が `10 01 0B`）。

```
F0 43 10 4C 10 00 0B 64 F7      AD1 の音量を 100 に
```

録音そのものは、この音量とは関係なく入る。

## 2. 録る（SAMPLING → REC）

パネルの **`SAMPLING`**（`gui.exe` のキーボードなら `M`）を押すと品書きが出る。

```
 EDIT  LOAD  SAVE
 REC   UTIL  RAM
```

`SELECT ◀ ▶` で **`REC`** に合わせて `ENTER`。

```
<REC>[         ]
 Sp=001     48s
```

`Sp=` が録り先の番号、その右が残りの時間。`SELECT ▶` で設定のページが変わる。

| ページ | 中身 |
|---|---|
| `Sp=001   48s` | 録り先の番号と、残りの秒数 |
| `TriggerLvl=off` | 音が入ったら録り始める引き金の高さ。`off` なら手で始める |
| `InputGain=line` | 入力の増幅（`line` / `mic`） |
| `InputSrc=AD1` | どの入口から録るか（`AD1` / `AD2` / `AD1+2`） |

`ENTER` を押すと録り始める。

```
<REC>[         ]
 Recording!  46s
```

もう一度 `ENTER` で止め、`EXIT` を押すと

```
 Keep Sample 001?
```

`ENTER` で残す（`EXIT` なら捨てる）。

## 3. 録れたものを見る・聞く（EDIT → SAMPLE）

`SAMPLING` → `EDIT` → `SAMPLE` → `ENTER`。

```
SMPL001 take001
 Name[]
```

`SELECT ▶` でページが変わる。

| ページ | 中身 |
|---|---|
| `Name[]` | 名前を付ける |
| `Start=0000000` | 鳴らし始める位置 |
| `End  =0089297` | 鳴らし終わる位置 |
| `Loop=off` | 繰り返し |
| `Trim` | いらないところを切る |

**`AUDITION` ボタン**（`gui.exe` のキーボードなら `Z`）を押すと、その場で試聴できる。

## 4. 音色にする（EDIT → VOICE）

録ったサンプルは、そのままでは MIDI から選べない。**音色（VOICE）に割り当てる**。

`SAMPLING` → `EDIT` → `VOICE` → `ENTER`。

```
PGM001:<NONE>
 Bank#=000
```

`SELECT ▶` で `Sp=` のページまで進み、`VALUE +` でサンプルを選ぶ。

```
PGM001:Voice001
 Sp=001 take001
```

これで音色 `PGM001` が `Voice001` になった。ほかのページは次のとおり。

| ページ | 中身 |
|---|---|
| `Bank#=000` | この音色を置くバンクの番号 |
| `Name[]` | 音色の名前 |
| `Sp=None` | **どのサンプルを鳴らすか**（ここで割り当てる） |
| `Level=***` | 音量 |
| `Pan=**` | 定位 |
| `Init` | まっさらに戻す |

## 5. MIDI から鳴らす

**バンクセレクト MSB を 16** にして、音色の番号をプログラムチェンジで送る。

| 送るもの | 値 |
|---|---|
| バンクセレクト MSB（CC0） | **16** |
| バンクセレクト LSB（CC32） | 0（`Bank#` で変えたならその番号） |
| プログラムチェンジ | 音色の番号 − 1（`PGM001` なら 0） |

```
B0 00 10   B0 20 00   C0 00      ch1 を Voice001 にする
```

LCD の音色の名前が `Voice001` に変わる。あとは普通に鍵盤を弾けば鳴る。

**ノート 60（中央のド）が、録ったときの高さ**。そこから半音ずつ上下する。
実際に 440Hz の音を録って確かめた結果が下（`--probe` で測った）。

| 弾いた鍵 | 出た高さ |
|---|---|
| 36 | 110.0 Hz |
| 48 | 220.0 Hz |
| 60 | **440.0 Hz**（原音） |
| 72 | 880.0 Hz |

## 6. SmartMedia に残す・読み戻す

サンプリング RAM は電源を切ると消える。残すならカードへ。

1. **カードを差す** … `gui.exe` ならパネル左下の差し込み口をクリックして
   「新しい SmartMedia を作って差す」（[gui.md](gui.md)）
2. **書式化** … `UTIL` → `CARD` → `Format` → `ENTER`。`Executing` が消えるまで待つ
3. **保存** … `SAMPLING` → `SAVE` → `ENTER` → `ALL+SEQ` → 保存先 → 名前（既定は `ALL_SEQ`）→ `ENTER`。
   `SAVING` が消えれば終わり
4. **読み戻し** … 別の機械（や次に起動したとき）で `SAMPLING` → `LOAD` → 同じファイルを選ぶ

`make test` の 7 番（`build/samptest.exe`）が、この保存と読み戻しを毎回確かめている。

## 7. DAW ではどうなるか

プロジェクトを保存すると、**サンプルも音色の割り当ても一緒に残る**（プラグインは機械まるごとの
状態を保存するため。[automation.md](automation.md) の版 2）。開き直すと、そのまま
バンク MSB 16 で鳴らせる。

確かめ方は、録って割り当てた機械の状態を保存し、別の機械に戻して同じ MIDI を送るというもので、
出音は元の機械と同じだった（rms 0.0470、440Hz 成分 0.03323 でどちらも一致）。

**ただしプロジェクトが大きくなる。** サンプリング RAM の中身がそのまま状態に入るので、
何も録っていなければ 30 万バイトほどの状態が、4MB 録ると 6MB ほどになる（詰める前の大きさ）。

## まだ書いていないもの

* `EDIT` の **`INST`** と **`KIT`**（複数のサンプルを鍵ごとに並べる・ドラムキットにする）。
  音色をいくつか作ってからでないと中身が確かめられないので、ここには書いていない
* `LOAD` / `SAVE` の `WAV`（PC で作った WAV を読み込む・書き出す）。カードへの出し入れは
  `tools/smcard.py` でできる（[gui.md](gui.md)）

## 手順を自分で確かめるには

パネルを文字だけで動かす道具に、押すたびに LCD を 1 行で出す `--trace` がある。

```bash
build/panel.exe <rom ディレクトリ> --keys "mode,left,left,left,enter" --trace
```

```
  mode       EDIT  LOAD  SAVE        |  REC   UTIL  RAM
  left       EDIT  LOAD  SAVE        |  REC   UTIL  RAM
  enter      SAMPLE   VOICE          |  INST     KIT
```

録音まで含めて確かめるには `build/samptest.exe <rom ディレクトリ> -v`（`make test` の 7 番）。
